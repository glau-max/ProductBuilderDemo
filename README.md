# Product Repo Template

Starter templates for product documentation — a PRD and a design brief.

## Contents

- **[PRD Template](docs/PRD-template.md)** — Structure for a Product Requirements Document covering problem statement, goals, user flows, milestones, design decisions, and success criteria.
- **[Design Brief Template](docs/design-brief-template.md)** — Structure for a design brief covering personas, user stories, user journeys, interaction states, empty states, edge cases, accessibility, and responsive behavior.

## Usage

Copy the templates into your project's `docs/` directory and fill in the sections relevant to your work.
